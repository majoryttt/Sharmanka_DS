# 📻 Музыкальный Discord бот «Шарманка»

**Шарманка** — современный, модульный и полнофункциональный музыкальный Discord-бот с чистым звуком и поддержкой ключевых стриминговых сервисов, включая **Яндекс.Музыку**, **YouTube**, **Spotify**, **SoundCloud**, **Apple Music** и прямые веб-радио потоки.

---

## ✨ Основные возможности

- 🟡 **Яндекс Музыка**:
  - Полная поддержка ссылок на треки, альбомы, плейлисты пользователей, чарты и страницы артистов.
  - Прямое воспроизведение в высоком качестве (320 kbps) при наличии токена аккаунта с Яндекс Плюс.
  - Поиск треков через префикс `ym: <запрос>` (например, `/play query: ym: Сплин Романс`).
  - Умный **fallback**: если токен не настроен или трек недоступен в регионе, бот автоматически находит и воспроизводит лучшую звуковую дорожку на YouTube.
- 🔴 **YouTube & YouTube Music**:
  - Воспроизведение треков по ссылке, плейлистов, Shorts, прямых трансляций, а также текстовый поиск по названию.
- 🟢 **Spotify**:
  - Поддержка ссылок на треки, альбомы и плейлисты (распознавание метаданных и стриминг).
- 🟠 **SoundCloud & Bandcamp**:
  - Прямой стриминг треков и сетов.
- 🌐 **Прямые аудиопотоки**:
  - Поддержка MP3, FLAC, OGG, WAV, AAC и потоков интернет-радио (.m3u8, Icecast/Shoutcast).
- 🎮 **Интерактивный UI с кнопками**:
  - Карточка «Сейчас играет» с обложкой, длительностью, источником и интерактивными кнопками управления (`⏯ Пауза/Плей`, `⏭ Пропуск`, `🔁 Повтор`, `🔀 Перемешать`, `📜 Очередь`, `⏹ Стоп`).
- ⚡ **Современные Slash-команды**:
  - Нативные команды Discord (`/play`, `/pause`, `/skip`, `/queue`, `/loop`, `/volume`, `/shuffle` и др.).
- ⏱ **Автоотключение**:
  - Автоматическое отключение и освобождение ресурсов при простое или если в голосовом канале не осталось слушателей.

## 🚀 Быстрый старт

### Способ 1: Локальный запуск (через Python)

#### Требования:
- Python 3.10+ (проверено на 3.12, 3.13, 3.14)
- Установленные системные пакеты `ffmpeg` и `libopus` (в Ubuntu/Debian: `sudo apt install ffmpeg libopus0`, в Arch: `sudo pacman -S ffmpeg opus`).

#### Инструкция:
1. Клонируйте репозиторий или откройте папку проекта:
   ```bash
   cd Шарманка
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # На Windows: .venv\Scripts\activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл конфигурации `.env`:
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` и укажите `DISCORD_TOKEN` (и `YANDEX_MUSIC_TOKEN` при наличии).

5. Запустите бота:
   ```bash
   python main.py
   ```

---

### Способ 2: Запуск в Docker / Docker Compose (Рекомендуется)

Docker-образ уже включает все необходимые мультимедиа-кодеки (`ffmpeg` и `libopus`).

1. Создайте `.env` файл:
   ```bash
   cp .env.example .env
   ```
   Укажите ваш `DISCORD_TOKEN`.

2. Запустите контейнер:
   ```bash
   docker compose up -d
   ```

3. Просмотр логов:
   ```bash
   docker compose logs -f
   ```

## 🔑 Настройка токенов и ключей

### 1. Как получить токен Discord бота:
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, введите имя (например, `Шарманка`).
3. Перейдите во вкладку **Bot** слева и нажмите **Reset Token** (скопируйте токен в `DISCORD_TOKEN` в файле `.env`).
4. Во вкладке **OAuth2 -> URL Generator**:
   - Выберите Scope: `bot`, `applications.commands`.
   - Выберите Bot Permissions:
     - `Send Messages`
     - `Embed Links`
     - `Attach Files`
     - `Connect`
     - `Speak`
     - `Use Application Commands`
5. Скопируйте сгенерированную ссылку внизу и пригласите бота на свой сервер.

---

### 2. Как получить токен Яндекс.Музыки (для прямого HQ стриминга):
Наличие токена Яндекс.Музыки открывает доступ к прямому стримингу 320 kbps и доступу к персональным плейлистам. Если токен не указан, бот всё равно будет принимать ссылки Яндекс Музыки, но искать аудиопоток на YouTube.

**Быстрый способ получения токена через браузер:**
1. Откройте сайт [music.yandex.ru](https://music.yandex.ru) в браузере и авторизуйтесь под своим аккаунтом.
2. Откройте панель разработчика (**F12** или `Ctrl+Shift+I`).
3. Перейдите на вкладку **Application** (или **Приложение** / **Хранилище**) -> **Cookies** -> `https://music.yandex.ru`.
4. Найдите строку с именем **`Session_id`** или перейдите на вкладку **Network** (**Сеть**), обновите страницу, найдите любой запрос к API и скопируйте заголовок `Authorization: OAuth <ваш_токен>`.
5. Вставьте полученное значение в `YANDEX_MUSIC_TOKEN` в файле `.env`.

---

### 3. Настройка Spotify (Опционально):
Если вы хотите использовать официальный Spotify API для быстрого парсинга больших приватных или кастомных плейлистов:
1. Зайдите на [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
2. Создайте приложение и скопируйте `Client ID` и `Client Secret`.
3. Вставьте их в `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` в файле `.env`.
*(Если они не указаны, бот использует публичные embed-эндпоинты и yt-dlp).*

## 📜 Список команд

| Команда | Описание |
| :--- | :--- |
| `/play <запрос>` | Воспроизвести трек по названию или ссылке (Яндекс, YouTube, Spotify, SoundCloud и др.) |
| `/pause` | Приостановить воспроизведение |
| `/resume` | Возобновить воспроизведение с паузы |
| `/skip` | Пропустить текущий трек |
| `/skipto <позиция>` | Перейти сразу к треку под указанным номером в очереди |
| `/stop` | Полностью остановить музыку, очистить очередь и отключить бота |
| `/queue [страница]` | Показать текущую очередь воспроизведения с разбивкой по страницам |
| `/nowplaying` | Показать интерактивную карточку текущего трека с кнопками управления |
| `/volume <1-150>` | Настроить громкость плеера |
| `/shuffle` | Перемешать треки в очереди |
| `/loop <режим>` | Переключить режим повтора: `off` (выкл), `track` (один трек), `queue` (вся очередь) |
| `/remove <позиция>` | Удалить выбранный трек из очереди |
| `/clear` | Очистить всю очередь ожидания |
| `/ping` | Проверить задержку подключения бота к Discord |
| `/help` | Показать подробную справку |

## 🛠 Архитектура проекта

```
Шарманка/
├── bot/
│   ├── cogs/
│   │   ├── general.py         # Команды /help и /ping
│   │   └── music.py           # Музыкальные слэш-команды (/play, /queue, /loop и др.)
│   ├── core/
│   │   ├── player.py          # GuildPlayer — управление сессией, таймерами и FFmpeg
│   │   ├── queue.py           # MusicQueue — логика очереди треков и режимов повтора
│   │   └── ui.py              # Discord UI (кнопки плеера и красивые Embed-карточки)
│   ├── extractors/
│   │   ├── base.py            # Базовые классы Track и BaseExtractor
│   │   ├── resolver.py        # Единый диспетчер резолвинга треков
│   │   ├── spotify.py         # Экстрактор Spotify
│   │   ├── yandex.py          # Экстрактор Яндекс.Музыки (треки, альбомы, плейлисты, чарты)
│   │   └── ytdlp.py           # Универсальный экстрактор yt-dlp (YouTube, SoundCloud, веб-потоки)
│   ├── client.py              # Инициализация SharmankaBot и синхронизация Tree
│   └── config.py              # Валидация и загрузка настроек окружения
├── tests/                     # Unit-тесты очереди и экстракторов
│   ├── test_extractors.py
│   └── test_queue.py
├── .env.example               # Шаблон настроек
├── Dockerfile                 # Docker-образ со всеми аудио-кодеками
├── docker-compose.yml         # Манифест быстрого запуска
├── main.py                    # Главная точка входа
└── requirements.txt           # Зависимости проекта
```
