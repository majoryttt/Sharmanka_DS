## ✨ Основные возможности

- 🟡 **Яндекс Музыка**:
  - Треки, альбомы, плейлисты пользователей, чарты и страницы артистов.
  - Прямой стриминг в высоком качестве (**320 kbps**) при наличии токена Яндекс Плюс.
  - Умный **fallback**: если трек недоступен или токен не указан, бот автоматически находит лучшую аудиодорожку.
  - Поиск треков через префикс `ym: <запрос>` (например: `/play ym: Сплин Романс`).

- 🍎 **Apple Music**:
  - Полная поддержка одиночных треков, альбомов и **крупных плейлистов (на 600+ песен)**.
  - Автоматическое извлечение публичного токена — **никаких платных подписок разработчика Apple**.
  - Быстрый поиск через префиксы `am: <запрос>` или `apple: <запрос>`.

- 🟢 **Spotify**:
  - Поддержка треков, альбомов и плейлистов.
  - Распознавание метаданных и мгновенный подбор аудиопотока.

- 🔴 **YouTube & YouTube Music**:
  - Треки по ссылке, плейлисты, Shorts, трансляции и текстовый поиск по названию.

- 🟠 **SoundCloud & Bandcamp**:
  - Поддержка треков и сетов.

- 🌐 **Прямые радио-потоки**:
  - MP3, FLAC, AAC, потоки интернет-радио (`.m3u8`, Icecast, Shoutcast).

## ⚡ Особенности движка и производительность

- 🚀 **Zero-Latency Audio**: умный префетчинг заблаговременно готовит следующий трек в фоне — переход между песнями в очереди происходит практически мгновенно.
- 🔊 **Идеальный звук**: защита от ускоренного воспроизведения («захлебывания») и оптимизированные буферы FFmpeg.
- 📌 **Статус голосового канала**: во время воспроизведения бот выводит текущий трек прямо в статус голосовой комнаты Discord.
- 🎛 **Интерактивный плеер**: карточка трека обновляется на месте и управляется удобными кнопками (Пауза, Пропуск, Повтор, Перемешивание, Очередь, Стоп).
- 🤫 **Эфемерные уведомления**: сервисные сообщения о добавлении треков в очередь видны только вам и не загромождают чат сервера.

## 🚀 Быстрый запуск

### Вариант 1: Запуск в Docker (Рекомендуется)

Docker-образ уже содержит все системные библиотеки и кодеки (`ffmpeg`, `libopus`).

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/majoryttt/Sharmanka_DS.git
   cd Sharmanka_DS
   ```

2. **Создайте файл конфигурации `.env`:**
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` и вставьте ваш токен Discord бота:
   ```env
   DISCORD_TOKEN=ваш_токен_бота
   ```

3. **Запустите контейнер:**
   ```bash
   docker compose up -d
   ```

4. **Просмотр логов:**
   ```bash
   docker compose logs -f
   ```

---

### Вариант 2: Локальный запуск (через Python)

#### Требования:
- Python 3.10+
- Установленные в системе `ffmpeg` и `libopus` (в Ubuntu/Debian: `sudo apt install ffmpeg libopus0`, в Arch: `sudo pacman -S ffmpeg opus`, в macOS: `brew install ffmpeg opus`).

#### Инструкция:
1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com/majoryttt/Sharmanka_DS.git
   cd Sharmanka_DS
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и укажите `DISCORD_TOKEN`:
   ```bash
   cp .env.example .env
   ```

5. Запустите бота:
   ```bash
   python main.py
   ```

## 🔑 Создание Discord бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **New Application**.
2. В разделе **Bot** нажмите **Reset Token** и скопируйте полученный токен в переменную `DISCORD_TOKEN` в файле `.env`.
3. В разделе **OAuth2 -> URL Generator**:
   - Отметьте Scopes: `bot`, `applications.commands`.
   - Отметьте Bot Permissions:
     - `Send Messages`
     - `Embed Links`
     - `Connect`
     - `Speak`
     - `Use Application Commands`
4. Откройте сгенерированную ссылку в браузере и пригласите бота на свой сервер.

## 📜 Список слэш-команд

| Команда | Описание |
| :--- | :--- |
| `/play <запрос>` | Воспроизвести трек по названию или ссылке (Яндекс, Apple Music, Spotify, YouTube и др.) |
| `/pause` | Приостановить воспроизведение |
| `/resume` | Возобновить воспроизведение с паузы |
| `/skip` | Пропустить текущий трек |
| `/skipto <номер>` | Перейти сразу к треку под выбранным номером в очереди |
| `/stop` | Остановить музыку, очистить очередь и выйти из канала |
| `/queue [страница]` | Показать текущую очередь воспроизведения |
| `/nowplaying` | Показать интерактивную карточку текущего трека с кнопками |
| `/volume <1-150>` | Настроить громкость воспроизведения (по умолчанию 100%) |
| `/shuffle` | Перемешать треки в очереди |
| `/loop <режим>` | Режим повтора: `off` (выкл), `track` (один трек), `queue` (вся очередь) |
| `/remove <номер>` | Удалить выбранный трек из очереди |
| `/clear` | Полностью очистить очередь треков |
| `/ping` | Проверить задержку бота до серверов Discord |
| `/help` | Показать справку по командам бота |
